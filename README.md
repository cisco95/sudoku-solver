# Sudoku Solver

A program for solving standard 9×9 Sudoku puzzles.

## How Sudoku Works

Fill each empty cell with a digit from 1 to 9 so that every row, column, and 3×3 box contains each digit exactly once.

## Puzzle Format

Represent a puzzle as a 9×9 grid. Use `0` for an empty cell; given digits should be between `1` and `9`.

## Usage

Run the solver using the project's entry point and provide a puzzle in the format it accepts. The solver returns a completed grid when a solution is found.

## Project Status

This project is a Sudoku-solving tool. See the source code for implementation details and the available input method.
